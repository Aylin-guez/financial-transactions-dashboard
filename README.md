
# Financial Transactions Analysis Dashboard

Interactive Power BI dashboard focused on financial transaction monitoring, customer analysis, and risk detection.

## Project Overview

This project analyzes transactional and customer financial data to identify:

- Transaction trends
- Customer spending behavior
- Credit score segmentation
- High-value transactions
- Transaction anomalies and errors

The dashboard was developed using Power BI with a relational data model connecting users, cards, and transactions datasets.
> Power BI source file available upon request.

---

## Features

### Executive Overview
- Total transaction volume
- Total customers
- Total cards
- Monthly transaction trends
- Card brand analysis
- Transaction method analysis

### Customer Analysis
- Income vs debt relationship
- Customer segmentation by credit score
- Transactions by age group

### Risk & Anomalies
- High-value transaction monitoring
- Transaction error analysis
- Interactive filtering by state
